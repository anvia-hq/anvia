Add schema-first Neo4j GraphRAG with explicit graph extraction, chunk and entity embeddings,
document-scoped replacement and deletion, vector and hybrid retrieval, bounded traversal, and an
Agent graph-search tool. Managed retrieval can explicitly hydrate provenance-linked source chunks,
and document writes return exact logical before-and-after change counts. Registrations enforce
exact property schemas and provenance, retrieval validates vector dimensions and traversal modes,
and the ownership-aware client supports async disposal.
